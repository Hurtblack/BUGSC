# 发布规则

本项目按“公开源码”和“正式 APK 发布”分开管理。

## 公开源码

公开到 GitHub/Gitee 的源码版本不应包含 SCM 后端受保护接口相关实现和内部对接文档，包括但不限于：

- SCM 登录、注册、找回/修改密码、邮箱验证码
- SCM 人机验证码协议、token 刷新、设备信任逻辑
- SCM 个人信息接口和私有字段解析
- SCM 交易创建、交易历史、交易状态操作
- SCM 私聊、未读消息、WebSocket 票据
- 完整接口路径、请求字段、鉴权方式说明文档

公开版本可以保留不涉及登录态的公共数据浏览能力；若某功能依赖上述接口，应隐藏入口、替换为网页跳转，或放到私有模块中。

## 正式 APK Release

正式 APK 可以从本地或私有仓库的完整代码构建，完整版本可以继续包含 SCM 账号、交易和聊天能力。

Release 页面可以上传完整 APK，但 README 需要说明：

> 开源版本不包含 SCM 账号、交易、聊天等服务端集成功能；正式发布 APK 由完整私有构建生成。

## 仓库公开注意事项

不要把包含 SCM 接口文档和实现历史的现有仓库直接改成公开仓库。若需要公开源码，应使用裁剪后的干净仓库，或在确认历史已清理后再公开。

## 推荐分支/仓库模型

- 私有完整仓库：日常开发、完整功能、构建正式 APK release。
- 公开裁剪仓库：用于源码展示和社区协作，不包含 SCM 受保护接口链路。
